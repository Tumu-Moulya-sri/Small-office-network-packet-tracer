Cisco Packet Tracer Infrastructure Simulation

Project Overview

This office network infrastructure was designed and simulated using Cisco Packet Tracer.

The network supports both wired and wireless communication between office devices.

Implemented Features

  • DHCP Automatic IP Assignment
  • Router and Switch Configuration
  • Wireless Access Point Setup
  • Server Hosting
  • Network Printer Integration
  • ICMP Ping Connectivity Testing
  • ARP and MAC Learning Observation
  • Simulation Mode Packet Analysis
